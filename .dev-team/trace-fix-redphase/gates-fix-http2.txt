## 1 · 实现（契约外补修，语义：默认关闭、可选开启）

`crates/server/src/routes.rs`
- `AppState` 增可选字段：`pub metrics_token: Option<String>`（doc 注明「为空时 `/metrics` 免鉴权」）；
  `AppState::new()` 默认 `None`；新增 builder `with_metrics_token(Option<String>)`（空串归一为 `None`）。
- 新增判定：`fn metrics_authorized(configured: Option<&str>, headers: &HeaderMap) -> bool`
  - `None` / 空白串 → **放行**（探针免鉴权、README 语义不变）；
  - 已配置 → 接受 `x-metrics-token: <token>`，或 `Authorization: Bearer <token>`（scheme 大小写不敏感）；
    比较走既有常量时间 `token_matches`；两者都不匹配 → 拒绝。
- `handle_metrics` 增 `headers: HeaderMap` 形参；鉴权失败 **先于任何 DB 访问** 返回
  `401` + 纯文本 `Unauthorized`（不回显期望/实际 token，不复用 F1 的 `Internal error` 文案）。
  其余 `/metrics` 输出与 C7 指标渲染完全不变。

`crates/server/src/main.rs`
- 启动时读取 `METRICS_TOKEN`（`std::env::var(...).ok().filter(|t| !t.is_empty())`），写入 `AppState.metrics_token`；
  未配置时行为与旧版逐字节一致。

## 2 · 集成用例（`crates/server/tests/api_test.rs`，+2 → 24）

- `test_metrics_stays_anonymous_when_token_not_configured`：未配置 → `/metrics` 200 且输出含既有指标；
  空串 `Some("")` 等价未配置 → 200。
- `test_metrics_requires_bearer_or_metrics_token_when_configured`：配置 `metrics-secret` 后
  ①无凭证 → 401 且响应体**逐字符等于** `Unauthorized`；②`x-metrics-token: wrong`、
  `Authorization: Bearer wrong`、`Authorization: metrics-secret`（缺 Bearer 前缀）→ 全部 401；
  ③`x-metrics-token: metrics-secret` 与 `Authorization: Bearer metrics-secret` → 均 200 且有指标输出；
  ④作用面隔离：`/healthz` 与 `GET /api/v1/traces`（带 admin token）不受影响。

## 3 · 物理收据（真实二进制 + curl，两种启动模式）

模式 A：`ADMIN_TOKEN=adm`（无 `METRICS_TOKEN`），端口 18301
  GET /metrics（无凭证）-> http_code=200，含 `pony_sentry_events_total` 3 行（既有输出不变）

模式 B：`ADMIN_TOKEN=adm METRICS_TOKEN=metrics-secret`，端口 18302
  无凭证                                  -> Unauthorized [http_code=401]
  x-metrics-token: wrong                   -> Unauthorized [http_code=401]
  Authorization: Bearer wrong              -> Unauthorized [http_code=401]
  Authorization: metrics-secret（缺 Bearer）-> Unauthorized [http_code=401]
  x-metrics-token: metrics-secret          -> http_code=200，含 events_total 3 行
  Authorization: Bearer metrics-secret     -> http_code=200，含 events_total 3 行
  GET /healthz（无凭证）                   -> {"db":"up","status":"ok"} [http_code=200]（鉴权不外溢）

   前者是运维探针面，后者是上报面）。

## 5 · 残余风险
- `/metrics` 命中鉴权失败时**不计入**任何指标（避免未授权方可刷计数器），如需审计请走访问日志。
- token 比较走 `token_matches`（常量时间逐字节）；未做速率限制/防爆破（与既有 admin token 同策略，非本任务范围）。
- 若部署侧把 `METRICS_TOKEN` 配进 Prometheus scrape 而未同步 job 配置，抓取将变 401（默认关闭故不影响现状）。
