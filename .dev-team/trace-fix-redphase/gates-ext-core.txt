## 逐项落点
1) **M-04**（`crates/ingest/src/sanitizer.rs`）
   - `SECRET_PATTERNS`：键允许单/双引号、`:`/`=` 两侧空白、值「带引号 ≥1 字符 / 裸值 ≥4 字符」，
     显式加入裸 `token`；`*tokens` / `token_count` 白名单不变（单测断言不被误改）。
   - 新增 `pub struct RedactionCounts { pub secrets: u64, pub paths: u64 }`（`lib.rs` 已 re-export）与
     `SanitizationPipeline::sanitize_trace_value(&Value) -> (Value, RedactionCounts)`（HTTP 约定签名）。
     配套 `sanitize_json_value_counted` / `sanitize_string_counted` / `sanitize_path_counted` /
     `sanitize_event_counted`；原入口全部保留并委托（无双套语义）。
   - 单测：`m04_redacts_five_secret_spellings`（5 写法：`password=`、`"password": "x"`、
     `'password': 'x'`、`token=`、`'api_key' = 'x'`）、`m04_token_metrics_are_not_redacted`、
     `m04_sanitize_trace_value_counts_secrets_and_paths`。
2) **I-02**（`crates/core/src/trace_v2.rs`）
   - `pub fn normalize_incoming_turns(payload: &mut Value) -> Vec<Value>`：非对象丢弃并产出
     `{"turn_index","reason":"invalid_turn"}`；`status` 非字符串 → `unknown`；`tool_calls` 非数组 → 删除。
   - 写路径（PG/SQLite `record_trace_locked`）调用并写入 `payload._warnings`（与旧值按 JSON 去重合集，上限 100）。
   - 单测：`i02_normalize_incoming_turns_drops_invalid_and_collects_warnings`、
     `i02_invalid_turns_are_dropped_and_warnings_persisted`（仓储级，含二次上报保留旧 warnings）。
3) **W-04**（迁移 + 仓储）
   - `migrations/0006_trace_turn_run_id.sql` + `migrations/postgres/0006_trace_turn_run_id.sql`：
     `trace_turns.run_id` 列 + `idx_trace_turns_run_id`；SQLite 由列探测守卫单事务执行，
     PG 走 `ensure_trace_turn_run_id_schema()`（逐条 autocommit/跳过已存在/CONCURRENTLY 索引）。
   - 写入填充：`turn.run_id` 优先，缺失回退 `payload` 顶层 `run_id`（`turn_run_id_of`），
     upsert 用 `run_id = COALESCE(excluded.run_id, trace_turns.run_id)`；hydration/backfill 同步填充。
   - `list_traces` / `count_traces` 的 `run_id` 过滤：
     `run_id = $1 OR EXISTS (SELECT 1 FROM trace_turns tt WHERE tt.session_id = traces.session_id AND tt.run_id = $1)`。
   - 单测：`w04_turn_run_id_column_and_filter_matches_turn_or_trace`（列填充两种来源 + 三向过滤 + 幂等重迁移）、
     `pg::w04_pg_run_id_filter_and_0006_schema`（0006 二次 ensure 0/0 + 列存在 + PG 过滤）。
4) **I-06**（截断 + 计数）
   - `TOOL_CALL_TEXT_MAX_CHARS = 20_000`；`normalize_incoming_turns` 内对每个 tool_call 的
     `output` / `arguments_summary` 截断并置 `truncated: true`，累计 `TRUNCATED_TOOL_TEXT`。
   - 进程级计数接口（供 `/metrics`）：`trace_truncated_total()` / `take_truncated_tool_text()`；
     合并丢失：`trace_merge_lost_total()` / `take_merge_lost_turns()`（旧终态覆盖新值时 `merge_turn` 累加）。
   - 单测：`i06_tool_call_text_is_truncated_at_limit_and_flagged`、
     `i06_long_tool_call_text_is_truncated_persisted_with_flag`（含 trace_turns 落盘值）、
     `v15_merge_lost_total_counts_old_terminal_overriding_new_value`（正/负例）。
5) **I-04/W-05**（仓储支撑）
