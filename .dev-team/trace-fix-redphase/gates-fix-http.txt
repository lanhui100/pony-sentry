## F2 关闭：指标 label 归一 + series 上限 512 + 渲染不整表 clone

代码：
- `const METRIC_LABEL_MAX_CHARS=64`、`METRIC_SERIES_MAX=512`、`METRIC_OVERFLOW_LABEL="overflow"`；
- `normalize_metric_label()`：按**字符**截断 64，非 `[A-Za-z0-9_.:-]` → `_`，全空 → `unknown`；
- `normalize_turn_status_label()`：受控集合（13 值：completed/succeeded/failed/error/cancelled/interrupted/
  timed_out/max_tokens/aborted/partial/running/unknown/other）大小写不敏感匹配，集合外 → `other`；
- `increment_capped()`：满 512 series 后新 key 折叠进 `overflow`，`AtomicBool::swap(true)` 保证**全进程只 WARN 一次**；
- 渲染改 `IngestMetrics::render_trace_metrics(&mut body)`：**持锁迭代直接写文本**（不再 `trace_snapshot()` 整表 clone），
  锁序 traces→turns→rejected 三段不嵌套。

集成用例：
- `test_trace_metrics_labels_are_normalized_and_bounded`：100KB project → `/metrics` 总长 < 8KB、label 恰为 64×`A`、
  不存在 65+ 字符 label；`proj/<weird>#` → `proj__weird__`；`status="Weird Status"` → `turn_status="other"` /
  `trace_turns_total{status="other"}`。
- `test_trace_metrics_series_are_capped_to_512_with_overflow`：520 个不同 project → series 行数 ≤ 513 且含
  `pony_sentry_traces_total{project="overflow",turn_status="overflow"}`。

## 偏离与说明（须知会 Lead）

1. **413 未并入 400**：请求体超限沿用 413 `Payload too large`（传输层限制，非上报语义错误）；如需「一律 400」改一行，
   但与 2MB 上限语义相悖，默认保留。
2. **F1 顺手修了 2 个非 `e.to_string()` 的同类泄漏**：①`PATCH /api/v1/issues/:id` 原把任意仓库错误映射为 404 并回显原文
   （现 NotFound=404 / 其余=500）；②`serde_json::to_value` 失败曾直出 serde 原文（v1.4-7 明确 serde 原文同样不外发）。
3. **`turn_status` 受控集合取 13 值**（含 C2 terminal 集合 + `partial`/`running`/`unknown`/`other`）；如契约要更严/更宽，
   改 `CONTROLLED_TURN_STATUSES` 一处即可。
4. **`overflow` 语义**：满额后**新** label 折叠进 `overflow`（已存在 label 继续自增、不折叠），故 513 行上限成立
   （512 普通 + 1 overflow）。overflow 计数 = 溢出上报次数（本例 11）。
5. **F10 需同 commit 文档**：`docs/trace-contract.md` §1/§4 由 Lead 同步（任务书已明确我只改代码）；本文件即代码侧口径。
6. **DB 故障用例用「删表」而非「持锁」**：断言点相同（`RepositoryError::Database` → 500 通用文案）但更快更稳（无 busy_timeout
   等待/抖动）；「DB 锁」路径等价，若需显式锁用例可再加（预计 5s 等待）。
