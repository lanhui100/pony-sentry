## §1 迁移文件与结构
- `migrations/0005_trace_turns.sql`（SQLite）：`trace_turns(session_id, turn_id, seq, status, payload,
  created_at, updated_at)` PK(session_id,turn_id) + 索引 `(session_id,seq)`、`(status)`；
  `traces` 增列 `turn_status NOT NULL DEFAULT 'unknown'`、`turns_count NOT NULL DEFAULT 0`、`note`；
  索引 `(run_id)`、`(turn_status)`、`(updated_at)`；`json_each` + `ON CONFLICT DO NOTHING` 幂等回填。
- `migrations/postgres/0005_trace_turns.sql`（PG）：同结构（payload JSONB、created_at/updated_at TIMESTAMPTZ），
  全部 `IF NOT EXISTS` / `ON CONFLICT DO NOTHING`，每次启动重放安全；`jsonb_array_elements … WITH ORDINALITY`
  回填。SQLite 的 ADD COLUMN 由 `migrate()` 列探测守卫 + 单事务包裹（范式同 0004）。
- 回填口径：同 turn_id 以**首个**为准；`turns_count` = 回填行数；`turn_status` = **最后一个** turn 的
  status（缺失 `unknown`）；seq = 数组下标（0 起）。
